# Деплой Бэкенда на ctrl+free (Гайд)

Этот гайд поможет вам развернуть серверную часть проекта (Telegram-бот + WebSocket сервер) на хостинге ctrl+free.

## Шаг 1: Подготовка архива
1. Перейдите в папку `backend` вашего проекта.
2. Убедитесь, что там находятся файлы:
   - `main.py`
   - `requirements.txt`
   - `presets.db` (база данных SQLite, создастся автоматически при первом запуске, но можно приложить пустую)
3. Выделите эти файлы и создайте `.zip` архив (например, `backend.zip`).

## Шаг 2: Создание приложения в панели ctrl+free
1. Зайдите в панель управления ctrl+free (например, Pterodactyl Panel или кастомная панель хостинга).
2. Выберите тип сервера (Язык): **Python**.
3. Задайте имя приложению (например, `tds-strategist-bot`).
4. В разделе сети или портов убедитесь, что серверу выдан порт.
   > **Важно:** В файле `main.py` указан порт `8080`. Если ctrl+free выдает другой случайный порт (например, `25565`), вам нужно изменить порт в `main.py` перед архивацией.
   ```python
   # Измените 8080 на порт, который выдал хостинг
   site = web.TCPSite(runner, '0.0.0.0', 8080)
   ```
5. Получите доменное имя вашего приложения (например, `app.ru.ctrlfree.host`).

## Шаг 3: Загрузка файлов
1. Перейдите во вкладку "File Manager" (Файловый менеджер) в панели.
2. Нажмите кнопку "Upload" и выберите ваш архив `backend.zip`.
3. После загрузки выделите архив и нажмите "Unarchive" (Распаковать).
4. Удалите сам архив `.zip`, чтобы он не занимал место.

## Шаг 4: Настройка параметров запуска и Переменных Окружения (ОЧЕНЬ ВАЖНО)
1. Перейдите во вкладку "Startup" (Параметры запуска).
2. Убедитесь, что стартовая команда выглядит примерно так: `python main.py` или `python3 main.py`.
3. Убедитесь, что переменная `REQUIREMENTS_FILE` указывает на `requirements.txt`.
4. **Добавление токена бота:** Найдите раздел переменных окружения (Environment Variables).
   Вам **ОБЯЗАТЕЛЬНО** нужно добавить переменную `BOT_TOKEN`. В качестве значения вставьте токен вашего бота (полученный от BotFather). Без этого сервер завершится с ошибкой (crash) при запуске!
   Также вы можете добавить переменную `ADMIN_ID` со своим Telegram ID.

## Шаг 5: Запуск и проверка
1. Перейдите во вкладку "Console" (Консоль).
2. Нажмите кнопку "Start" (Запустить).
3. В консоли должно появиться сообщение об установке пакетов (aiohttp, aiogram, aiosqlite).
4. Затем вы должны увидеть:
   ```
   INFO:root:aiohttp server started on port 8080
   ```
5. Проверьте бота: напишите `/start` вашему боту в Telegram. Он должен ответить!

## Шаг 6: Настройка Frontend
После успешного деплоя вернитесь в ваш Frontend проект и обновите файл `.env`:
```env
VITE_API_URL=https://app.ru.ctrlfree.host
VITE_WS_URL=wss://app.ru.ctrlfree.host/ws
```
*(Замените `app.ru.ctrlfree.host` на ваш реальный домен)*.

Теперь ваш калькулятор и Telegram-бот работают в связке!
